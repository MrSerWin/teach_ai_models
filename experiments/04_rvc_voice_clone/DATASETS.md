# Источники датасетов для 5 голосов

Ресерч от 2026-05-20. Приоритет — тюркские языки с полным покрытием фонем
крым.тат: ñ /ŋ/, q /q/ увулярная, ğ, ç, ş.

**Полное покрытие фонем**: крымскотатарский, татарский, азербайджанский,
казахский, киргизский, башкирский, узбекский.
**Частичное (нет /q/)**: турецкий — допустимо, но добавьте 3–5 мин крым.тат для
«заземления» специфичных звуков.

## ⚠️ Важное ограничение RVC

**RVC обучается на ОДНОМ голосе.** Поэтому большинство «открытых датасетов»
(TatarTTS, Common Voice, KazakhTTS2) НЕ подходят как первичный источник:
они либо мульти-спикер (модель будет «усреднённой»), либо single-speaker но
с слабой фонетикой (speech-uk/* — см. опыт пользователя).

**Реалистичный путь** = выбрать ОДНОГО автора аудиокниг / подкастера /
ведущего YouTube с подходящим тембром и нарезать 20–30 мин его голоса через
`prep-rvc-dataset.sh`. Готовые корпуса — в лучшем случае supplement (3–5 мин
для подмеса фонем).

## 1. Автор/рассказчик (М, 35–45, тёплый)

1. **Sesli Kitap Dünyası** — youtube.com/c/SesliKitapDünyası — турецкие
   аудиокниги, чтец Burak Aşkın, 35–45, 20+ часов. Сильное совпадение по тембру.
   *Турецкий — добавить крым.тат сэмпл.*
2. **Türkçe Sesli Kitap** — youtube.com/channel/UCXJ-_OmnvRTl1gMRsTSYPgA — несколько
   мужских голосов, фильтровать по низким тёплым.
3. **Krym.Realii (Qırım Aqiqat)** — youtube.com/@krymrealii — крым.тат ведущие.
   ~10 ч мужского голоса. **Высший фонетический приоритет.**
4. **TatarTTS** — huggingface.co/datasets/issai/TatarTTS — студийное качество, один
   профессиональный мужской голос, ~70 ч, CC.
5. **KazakhTTS2** — ISSAI, 2 мужских профессиональных диктора, 271 ч.

---

## 2. Мальчик (М, 8–10) — сложно, см. отдельную секцию ниже

1. **Azerbaijani Fairy Tales** — youtube.com/c/AzerbaijaniFairyTales — часть
   эпизодов озвучена мальчиками 8–12. *Азербайджанский — полное покрытие.*
2. **Usaq TV** — youtube.com/@UsaqTV — азерб. детский канал.
3. **TRT Çocuk** — youtube.com/trtcocuk — турецкий детский ТВ; интервью с детьми
   в документальных сегментах.
4. **Mozilla Common Voice (tt, kk, ky, az)** — фильтр `age=teens, gender=male`.
   Несколько часов суммарно, качество разное.
5. **QIRIM WEB TV** — youtube.com/user/qirimwebtv — искать «balalar»; немного,
   но родная фонетика.

Реалистично: нарезать 10–30 мин из десятков коротких клипов.

---

## 3. Учительница (Ж, 30–40, мягкая)

1. **TatarTTS** — профессиональный женский татарский голос, 30+ ч, студия.
   **Лучший вариант.**
2. **KazakhTTS2** — 3 женских голоса, один подходит по возрасту, 50+ ч каждый.
3. **Azerbaijani Fairy Tales** — взрослая женщина-чтец, тёплый педагогический
   тон. 10+ часов.
4. **Hikaye Perisi** — youtube.com/@hikayeperisii — турецкая женщина-чтец
   детских книг, мягкий тон.
5. **Krym.Realii** женские ведущие — родной крым.тат.

---

## 4. Девочка (Ж, 7–9) — самое сложное

1. **Azerbaijani Fairy Tales** — несколько сказок читают девочки 7–10.
2. **Bala.tatar** — bala.tatar — татарские сказки, 140 шт, часть с детскими
   голосами. *Родная татарская фонетика — приоритет.*
3. **TRT Çocuk Kitaplık** (приложение) — некоторые книги читают дети-актёры.
   Только в приложении, нужна запись с экрана.
4. **YouTube: «şiir okuyan kız», «ертегі айтып беретін қыз»** — школьные
   декламации стихов, дочки 7–10. Сшивать из десятков коротких клипов,
   половину выкинуть по качеству.
5. **Kookla TV** — youtube.com/c/KooklaTV — оговорка: в основном **взрослые
   имитируют детей**, не годится как первичный источник.

---

## 5. Дедушка (М, 65–75, хриплый)

1. **Dede Korkut hikayeleri sesli** (поиск YouTube) — пожилые мужчины-чтецы
   фольклорных эпосов, медленная гравийная подача. Несколько каналов с 1–5 ч.
2. **Demokrat Dede** — youtube.com/@demokratdede — турецкий пожилой
   мужской голос. Несколько часов.
3. **Krym.Realii** — поиск «qartlar», «ihtiyar» — реальные крым.тат
   старики. Ограниченно, но родная фонетика (1–3 ч).
4. **Tatar-Bashkir RFE/RL** — pressroom.rferl.org/service/tatar-bashkir-service —
   интервью с пожилыми на татарском/башкирском.
5. **Common Voice (kk, tt, az, ky)** — `age=sixties/seventies, gender=male`.

## Чисто крымскотатарские источники

Подмешивать 3–5 мин в каждый датасет для «заземления» фонем:

- **QIRIM WEB TV** — youtube.com/user/qirimwebtv — самый активный общий канал на крым.тат.
- **Krym.Realii** — youtube.com/@krymrealii — Radio Liberty крым.тат служба, ~440k подписчиков, сотни часов.
- **ATR TV** — youtube.com/@ATRchannel — новости, ток-шоу, детские сегменты, музыка.
- **Crimean Tatars** — youtube.com/c/CrimeanTatars — документалка, культура.

### Готовые открытые датасеты на Hugging Face

**⚠️ Не использовать как первичные доноры:**
- `speech-uk/tts-crh-arslan`, `speech-uk/tts-crh-abibullah`, `Yehor/qirimtatar-tts` —
  пользователь работал с этими корпусами и оценивает произношение как
  недостаточно чистое (звуки крым.тат идут с дефектами). Не подходят как
  фонетический референс для RVC. В лучшем случае — supplement, и только после
  ручной проверки конкретных сэмплов.

**Возможно полезное:**
- `facebook/mms-tts-crh` — pretrained крым.тат TTS. Синтетика, не натуральная
  речь — но при необходимости можно сгенерировать фонетически сбалансированные
  фразы. **Проверять качество перед использованием.**
- `egorsmkv/qirimtatar-tts-datasets` — github.com/egorsmkv/qirimtatar-tts-datasets —
  индекс открытых крым.тат датасетов (используйте как навигацию, оценивайте
  каждый отдельно).

## Особое: детские голоса

Дефицит из-за этики/согласий. Стратегии в порядке убывания качества:

1. **Азербайджанские детские аудиокниги** — единственный надёжный источник
   с реальными детьми и полным покрытием фонем.
2. **Турецкие школьные декламации** — поиск `şiir okuyan çocuk`,
   `Atatürk şiiri okuyan ilkokul`. Сотни коротких клипов, 50% брак по качеству.
3. **Татарский bala.tatar + Chulpan Nasyrova** — youtube.com/@ChulpanNasyrova —
   взрослая женщина, но есть плейлисты с детскими чтениями.
4. **Казахские/киргизские детские аудиокниги** — kitap.kz/audio-book,
   kyrgyz-audio.com.
5. **Common Voice age=teens** — суммарно по tt+kk+az+ky наберётся 30 мин – 2 ч.
6. **Fallback: pitch-shift взрослого** — если детского материала совсем нет,
   обучить на молодой женщине/мужчине и поднять pitch на inference (+6..+9).
   Качество хуже настоящего детского, но рабочий план Б.

**Бюджет времени:** взрослый голос ≈ 0.5 дня поиска; детский ≈ 2–3 дня.

## Самые ценные находки

Если из всего списка выбрать «обязательно посмотреть в первую очередь»:

| Голос | Главный источник |
|---|---|
| Автор | **TatarTTS** мужской (студия, ~70 ч, полное покрытие фонем) или Sesli Kitap Dünyası (турецкий) |
| Учительница | **TatarTTS** женский (студия, 30+ ч, родная фонетика) |
| Дедушка | Dede Korkut каналы YouTube + Krym.Realii старики |
| Мальчик | **Azerbaijani Fairy Tales** + ручная нарезка |
| Девочка | **Azerbaijani Fairy Tales** + школьные декламации YouTube |

**Важно:** публичные крым.тат TTS-корпуса (speech-uk/*, Yehor/*) **не годятся**
как первичные доноры — у них слабое произношение специфичных звуков. Для
фонетического заземления нужно искать живых носителей через Krym.Realii / ATR /
QIRIM WEB TV (живой эфир, интервью) и нарезать вручную.
